# Бэкенд форума presidentmodel.io/forum/

API для страницы форума (сама страница лежит в ветке `main`, папка `forum/`, и публикуется GitHub Pages):
вопросы и ответы, мнения по темам, PRESIDENT AI SEARCH (OpenAI Responses API + web_search).

## Внешние обсуждения

Список из 70 тем задан в `discussion_sources.py`. Сервер раз в 5 минут загружает
их в фоне, очищает HTML до обычного текста и сохраняет результат на диске Render
в `discussions.json`. Страница форума делает один запрос только за заголовками,
а сохранённый текст или пересказ запрашивает по раскрытию конкретной темы.
В браузере нет запросов к исходному форуму и нет ключей/вызовов нейросети.

По умолчанию `DISCUSSION_IMPORT_MODE=summary`: хранится нейтральный пересказ с
указанием внешнего источника. При наличии `OPENAI_API_KEY` пересказ создаёт
Responses API; если сервис временно недоступен, используется короткая локальная
выжимка. Установить `DISCUSSION_IMPORT_MODE=full` можно только если оператор
подтвердил право на полный импорт: тогда сервер сохраняет очищенный текст
сообщений в исходном порядке. Повторный пересказ делается только при изменении
текста источника; недоступный источник не затирает последнюю сохранённую версию.

## Внешние отзывы о моделях

Страница `https://rlc.intimcity.beer/admin_pseudo.php` импортируется в том же
фоновом цикле и сохраняется в `model_reviews.json`. Во вкладке «Отзывы о
моделях» это отдельный блок «Лжесотрудники»: каждая центральная карточка
сохраняется отдельно с фотографией, подписью и ссылкой на подробный ответ.
Подробность отдаётся из API только по нажатию, уже без запроса к источнику.
Шапка, меню, боковые колонки, HTML и скрипты не импортируются. AI-пересказ не
используется; случайные контакты и секреты маскируются. При сбое страницы сайт
показывает последнюю сохранённую версию с датой обновления.

Python 3.9+, без зависимостей. Хостинг — Render, конфигурация в `render.yaml`.

## Запуск на Render
1. render.com → войти через GitHub.
2. New → Blueprint → репозиторий `Iamkarat/-president`, ветка `forum-backend`.
3. Вставить ключ в поле `OPENAI_API_KEY` (platform.openai.com → API keys) и подтвердить.

Сервис станет доступен по адресу https://presidentmodel-forum-api.onrender.com —
он уже прописан в `forum/config.js` (`apiBase`) в ветке `main`.

## Настройки (переменные окружения)
Описаны в начале `server.py` и `ai_search.py`. Главное:
- `AI_DAILY_BUDGET_USD` — дневной лимит расходов на OpenAI (сейчас $3);
- `AI_HOURLY_QUICK` / `AI_HOURLY_DEEP` — запросов в час с одного IP;
- `FORUM_PASSWORD` — закрыть API паролем (HTTP Basic Auth).
- `DISCUSSION_IMPORT_MODE` — `summary` (по умолчанию) или `full` при явном праве на полный импорт;
- `DISCUSSION_REFRESH_SECONDS` — интервал фонового обновления, по умолчанию `300`;
- `DISCUSSION_IMPORT_CONCURRENCY` — параллельных запросов к источникам, по умолчанию `3`;
- `DISCUSSION_SOURCE_TIMEOUT` — тайм-аут одного источника в секундах, по умолчанию `20`.
- `DISCUSSION_SOURCE_COOKIE` — полное значение HTTP-заголовка `Cookie` для `rlc.intimcity.beer`.
  Добавляется только в Secrets/Environment Render, не в `.env`, код или чат. Нужен, если
  источник перенаправляет сервер на страницу авторизации.
- `MODEL_REVIEW_SOURCE_URL` — адрес внешней страницы отзывов; по умолчанию
  `https://rlc.intimcity.beer/admin_pseudo.php`. Cookie используется тот же
  `DISCUSSION_SOURCE_COOKIE` и остаётся только на сервере.

    OPENAI_API_KEY=... python3 server.py   # http://127.0.0.1:8734
